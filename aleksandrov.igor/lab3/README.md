# Лабораторная работа 3

## Задание

Вариант 6.

Реализовать функцию intersection(arr1, arr2), которая возвращает массив общих
элементов.

## Реализация

Использовалась структура данных `Set` для первого массива, что обеспечивает
быструю проверку наличия его элементов при переборе второго массива. В конце
концов, очистка результата через `Set` гарантирует уникальность элементов.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
