# Лабораторная работа 2

## Задание

Вариант 6.

Написать функцию isPerfectNumber, проверяющую, является ли число "совершенным"
(сумма делителей равна числу, исключая само число).

## Реализация

Вместо классического решения с перебором делителей было решено использовать
теорему Евклида-Эйлера. Функция проверяет на простоту только генерируемое в
процессе соответствующее число Мерсенна. Нечётные числа и значения, меньшие или
равные 1, отсекаются сразу, а также есть защита от переполнения знакового целого
числа.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
