# Лабораторная работа 2

## Задание

Вариант 27. Написать функцию toRoman(num), преобразующую целое число от 1 до
3999 в римскую запись.

## Реализация

Заранее задан массив пар "число - римский символ" в порядке убывания значений,
включающий комбинации CM, CD, XC, XL, IX и IV. Далее в цикле по этому массиву
для каждой пары проверяется, не меньше ли текущее значение value числа пары.
Пока это так, во вложенном цикле символ пары добавляется в конец строки result,
а из value вычитается число пары. После перебора всех пар накопленная строка
result возвращается как результат функции.
