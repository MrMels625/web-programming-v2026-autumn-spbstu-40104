# Лабораторная работа 3

## Задание

Вариант 27. Реализовать функцию rotateArray(arr, steps), которая сдвигает массив
вправо на steps элементов.

## Реализация

Если входной массив пустой, функция сразу возвращает пустой массив. Далее
вычисляется число сдвигов: остаток от деления количества шагов на длину массива,
приведённый к неотрицательному значению. Если после этого сдвигов не остаётся,
возвращается копия исходного массива без изменений. Иначе результат собирается
из двух частей: сначала идут элементы с конца массива в количестве, равном числу
сдвигов, а за ними — оставшиеся элементы с начала массива.
